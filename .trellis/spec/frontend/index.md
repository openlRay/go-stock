# 前端开发规范

## 概述

本目录沉淀当前 Vue 3、Vue Router 与 Naive UI 前端的全局可执行规范。规范描述跨页面、跨组件可复用的约束；单个组件的 props、文件路径、业务字段和本次实现选择应记录在对应 task 的 `design.md`。

| --- | --- | --- |
| [前端架构规范](./architecture-guidelines.md) | 路由加载、页面编排、业务组件与公共组件边界 | 生效中 |
| [表单弹框规范](./dialog-guidelines.md) | 应用级弹框职责、视觉、交互和验证要求 | 生效中 |
| [前端质量规范](./quality-guidelines.md) | 代码注释要求与按风险选择验证范围 | 生效中 |

## 开发前检查

修改前端代码前：

1. 阅读[前端架构规范](./architecture-guidelines.md)和[前端质量规范](./quality-guidelines.md)。
2. 修改弹框时额外阅读[弹框规范](./dialog-guidelines.md)。
3. 判断需求属于路由页面、业务组件还是跨业务公共组件。
4. 修改弹框时区分应用级稳定骨架与业务内容职责。
5. 根据修改风险选择能够证明正确性的最小验证范围。

## 质量检查

- 路由记录必须通过 `dynamic import()` 按需加载。
- 跨业务复用的 UI 放在 `components/common/`；路由页面和业务组件不得放入该目录。
- 非显然的约束、兼容逻辑和职责边界必须用中文注释说明“为什么”。
- 自动化测试和浏览器验收按修改风险选择，不得把它们当作每次改动的固定仪式。
