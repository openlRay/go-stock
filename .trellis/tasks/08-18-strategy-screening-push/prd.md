# 策略定时选股推送

## Goal

让用户在定时任务中选择一条“我的策略”，按 Cron 计划自动执行自然语言选股，并将本次命中的股票结果通过现有任务完成通知渠道推送，无需每次手动打开指标选股页面。

## Background

- 自定义策略已持久化为 `CustomStrategy`，核心执行条件为 `Query`；当前策略页面只支持手动执行、保存和删除，不包含调度或通知字段（`backend/models/models.go:1726`、`frontend/src/components/SelectStock.vue:299`）。
- 股票筛选统一通过 `SearchStockApi.SearchStock` 调用东方财富智能选股接口，页面 RPC 当前请求上限为 5000 条（`backend/data/search_stock_api.go:25`、`app_common.go:213`）。
- 定时任务已有统一执行结果结构和 `NotifyOnCompletion` 通知边界，可向全局启用的本地/Web、飞书和钉钉渠道发送结果（`backend/models/models.go:1498`、`app_cron_notification.go:15`）。
- 当前 `custom` 定时任务类型只是返回固定摘要的占位实现，不能执行选股策略（`backend/agent/cron_task_api.go:464`）。

## Requirements

### R1 新增策略选股任务类型

- 定时任务类型新增独立的“策略选股推送”，不得复用含义不明确的 `custom` 占位类型。
- 创建和编辑该类型任务时，从“我的策略”列表中选择一条现有策略，不要求用户重复输入自然语言条件。
- 该任务类型必须启用执行完成推送；后端必须像 `motto_push` 一样强制该约束，避免绕过前端造成“执行但不推送”。

### R2 定时执行策略

- 任务参数持久化稳定的策略 ID；执行时重新读取最新策略内容，使用户编辑策略后后续任务自动使用新条件。
- 策略已删除、条件为空、东方财富标识未配置、外部请求失败或响应格式不合法时，任务以安全、明确的失败摘要结束，并沿用通用失败通知。
- 任务执行必须复用现有 `SearchStockApi`，不建立第二套自然语言解析或股票筛选实现。

### R3 推送选股结果

- 一次任务执行只产生一次完成通知，内容至少包含任务名、策略名、策略条件、命中总数、股票代码和股票名称。
- 表单提供推送数量选项 10、20、50、全部，默认 20；通知显示总命中数。选择固定数量时列出前 N 只，选择“全部”时尽量列出本次返回的全部股票。
- 命中为空时仍视为一次成功筛选，并明确推送“本次没有符合条件的股票”，而不是伪装为接口错误。
- 推送正文必须遵守现有通知长度上限，不能因策略命中数过大生成不可发送的消息；“全部”超过渠道安全长度时必须标明实际展示数量，不得声称已经完整列出。
- 结果推送复用现有本地/Web、飞书和钉钉全局渠道设置，不新增通知供应商或账号配置。

### R4 管理与兼容

- 编辑已有策略选股任务时正确回显策略；普通任务和现有 `motto_push` 行为保持不变。
- 策略下拉列表为空时提供明确提示，并阻止创建无效任务。
- 定时调度和“立即执行”必须走相同的策略执行与结果推送链路。

## Acceptance Criteria

- [x] AC1：定时任务类型中可选择“策略选股推送”，表单展示“我的策略”下拉框和 10/20/50/全部推送数量选项，默认数量为 20，并保存策略 ID 与数量。
- [x] AC2：新建、编辑和重新打开任务时策略选择一致；未选择策略或策略列表为空时无法提交。
- [x] AC3：后端执行时按策略 ID 读取最新 `Query`，调用现有选股 API，并把命中股票格式化为统一 Cron 执行结果。
- [x] AC4：有命中、无命中、策略被删除、外部接口失败四类结果均产生正确的任务状态和安全通知内容。
- [x] AC5：该任务类型的 `NotifyOnCompletion` 始终为 `true`；调度执行和立即执行各只推送一次。
- [x] AC6：普通定时任务、推送格言、自定义策略 CRUD 和手动选股功能无回归。
- [x] AC7：后端定点测试和前端构建通过；验证范围覆盖参数解析、策略查询、结果格式化和强制推送约束。

## Out of Scope

- 不实现本地选股解析器、回测、买卖点、仓位或止损规则。
- 不新增单独的策略通知渠道、联系人或 Webhook 配置。
- 不做策略结果历史版本、收益追踪或跨次命中变化统计，除非后续明确扩展。

## Technical Notes

- 推送数量只控制通知中列出的股票数量，不改变筛选接口返回的实际命中总数；`0` 表示“全部”，通知必须同时展示总命中数和实际展示数量。
- 任务保存稳定的策略 ID，不复制策略名称和 `Query`，保证策略编辑后定时任务自动采用最新条件。
